I built TicTacToe as a deeper React project to go beyond basic component rendering and work with real game state, multiplayer synchronization, authentication, and opponent logic.

The game supports both AI and real-time multiplayer gameplay. For single-player matches, the AI uses an Elo-based difficulty system, allowing different levels of opponents rather than relying on a simple fixed difficulty setting. This gives the game a progression system where the strength of the opponent is tied to a rating-based model.

For multiplayer, players can authenticate through Firebase and play with friends in real time. Game state is synchronized through Firebase so that moves made by one player are reflected immediately for the other player without requiring a page refresh.

The core game logic handles turn management, valid moves, win and draw detection, and automatic highlighting of winning combinations. React manages the local UI state while Firebase handles authentication and the persistent, synchronized multiplayer state.

The project gave me practical experience building an interactive application where game logic, asynchronous real-time data, authentication, and UI state all have to work together reliably.
