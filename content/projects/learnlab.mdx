LearnLab was built during a hackathon, where the real constraint wasn't the tech — it was coordinating six people toward one working product in a very short window. As lead, my job covered both directions: making sure the pieces different teammates were building would fit together, and building a meaningful chunk of the frontend myself.

The app is a Learning Management System: users authenticate, browse course content, and view course documents directly in-app rather than downloading them — the in-app document viewer was one of the more fiddly pieces to get right, backed by Firebase Cloud Storage for the underlying files and Firestore for course metadata.

The harder problem, though, was integration. With frontend and backend built in parallel by different people, keeping data contracts consistent — what shape the user object took, how content documents were structured in Firestore — was the difference between a demo that worked on stage and one that didn't. Managing that consistency, while also shipping frontend work myself, was the actual project.
